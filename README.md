# FDump
A lightweight, high-performance Rust CLI tool that dumps files and directory structures into a single formatted text stream.

## What is this?
When sharing context with LLMs, code reviewers, or team members, copying files one by one is slow and loses structural context. FDump solves this by walking your project tree, rendering a visual representation of your file hierarchy, and appending the content of each file into a single output stream.

## Key Features
- Visual Tree + Content: Generates an ASCII tree diagram followed by the full contents of all specified files.
- Privacy Mode (-s): Strips user-specific root path prefixes (e.g., /Users/username/) to prevent leaking private path structures in shared dumps.
- Path Deduplication & Squashing: Resolves overlapping file and directory inputs so no path is processed twice.
- Recursive Expansion: Automatically traverses subdirectories to collect all nested files.
- Cross-Platform: Native path handling across macOS, Linux, and Windows.

## Example Usage

Dump a folder while stripping local path prefixes, and pipe the output straight to your clipboard:
`fdump src/ -s | xclip -selection clipboard`

Output:
```plaintext
src/
├── err.rs
├── files.rs
├── main.rs
└── tree.rs

==== src/err.rs ====
#[derive(Debug)]
pub enum FDumpError { ... }
...
```
